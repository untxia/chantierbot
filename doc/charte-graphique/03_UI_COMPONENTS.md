# Design System UI

## Sidebar
Fond Dark Navy #0B1020.
Élément actif : bleu/violet très léger.
Icônes outline.

## Cards
Fond blanc.
Rayon 14 px.
Padding 20–24 px.
Bordure très légère.
Ombre discrète.
Hover : translation verticale maximale de 2 px.

## Inputs
Rayon 10 px.
Focus : bordure Primary + halo très léger.
Placeholder : texte secondaire.

## Notifications
Succès : vert.
Information : bleu.
Attention : orange.
Erreur : rouge.
Animation : fade + slide, ~250 ms.

## Badges
Petits, lisibles et discrets.
Exemples : Actif, En cours, Terminé, En attente, ✨ IA.

## Graphiques
Palette prioritaire : bleu / violet.
Vert = positif.
Orange = attention.
Rouge = négatif.
Éviter les palettes arc-en-ciel.

## Micro-interactions
Hover : 150–200 ms.
Apparition : 200–300 ms.
Bouton : légère compression au clic.
Éviter les animations permanentes inutiles.
