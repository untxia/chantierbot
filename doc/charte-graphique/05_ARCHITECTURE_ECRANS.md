# Architecture visuelle des écrans

## Connexion
Disposition desktop en deux zones :
- gauche : identité + mascotte
- droite : formulaire

## Dashboard
Ordre de lecture :
1. Bonjour / contexte
2. KPI
3. activité principale
4. projets / tâches
5. informations secondaires

## Navigation
Accueil
Projets
✨ IA
Analyses
Paramètres

## Mobile
Navigation compacte ou bottom navigation :
Accueil / Projets / IA / Plus

## Philosophie
L'utilisateur doit comprendre le dashboard en environ 3 secondes :
où il est, ce qui est important et quelle action effectuer ensuite.
