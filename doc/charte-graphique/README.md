# Charte graphique du logiciel

Dossier de référence — version 1.0.

La charte est basée sur Manrope, Electric Blue, Electric Violet et Dark Navy, avec une identité SaaS + IA et une mascotte d'ouvrier.

Le fichier `02_DESIGN_TOKENS.css` peut servir de base aux variables du projet.
`07_CSS_STARTER.css` contient un starter CSS directement réutilisable.
